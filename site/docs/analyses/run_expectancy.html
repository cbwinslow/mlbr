The 24 Base-Out Run Expectancy Matrix (RE24)

  • Show All Code
  • Hide All Code
  • View Source

Empirical valuation of game states and event run values across 23.8M Retrosheet plays

Introduction

At any given moment in a baseball game, the state of the half-inning can be partitioned into 24 discrete base-out states: - 3 Out States: 0 outs, 1 out, 2 outs - 8 Base Occupancy States: Empty (___), 1st (1__), 2nd (_2_), 1st & 2nd (12_), 3rd (__3), 1st & 3rd (1_3), 2nd & 3rd (_23), and Bases Loaded (123).

Run Expectancy (RE) is the expected number of runs that will be scored from that point until the end of the half-inning. It forms the foundational bedrock of modern sabermetrics: \[\Delta \text{RE} = \text{RE}_{\text{state}_{t+1}} - \text{RE}_{\text{state}_t} + \text{Runs Scored on Play}\]

This difference (\(\Delta \text{RE}\)) is the empirical Run Value of any baseball event (single, strikeout, stolen base, double play), from which Linear Weights, wOBA constants, and WAR are derived.

Extracting Plays via DuckDB

Using mlbr’s zero-copy DuckDB connection, we compute future half-inning runs directly over a sample of 150,000 modern regular season plays:

Code 
suppressPackageStartupMessages({
  .libPaths(c("/mnt/storage/R/library", .libPaths()))
  library(mlbr)
  library(duckdb)
  library(dplyr)
  library(ggplot2)
  library(tidyr)
  library(knitr)
  library(viridis)
})

con <- lake_duckdb()

# Compute base-out state and future inning runs using window functions
re24_raw <- DBI::dbGetQuery(con, "
  WITH play_events AS (
    SELECT 
      GAME_ID,
      TRY_CAST(INN_CT AS INTEGER) AS inn,
      BAT_HOME_ID,
      TRY_CAST(EVENT_ID AS INTEGER) AS event_id,
      TRY_CAST(OUTS_CT AS INTEGER) AS outs,
      CASE WHEN BASE1_RUN_ID != '' AND BASE1_RUN_ID IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN BASE2_RUN_ID != '' AND BASE2_RUN_ID IS NOT NULL THEN 2 ELSE 0 END +
      CASE WHEN BASE3_RUN_ID != '' AND BASE3_RUN_ID IS NOT NULL THEN 4 ELSE 0 END AS base_state,
      COALESCE(TRY_CAST(EVENT_RUNS_CT AS INTEGER), 0) AS runs_scored
    FROM retro_plays
    WHERE TRY_CAST(OUTS_CT AS INTEGER) BETWEEN 0 AND 2
      AND TRY_CAST(INN_CT AS INTEGER) BETWEEN 1 AND 9
    USING SAMPLE 150000 (reservoir)
  ),
  half_innings AS (
    SELECT 
      *,
      SUM(runs_scored) OVER (PARTITION BY GAME_ID, inn, BAT_HOME_ID) AS total_inn_runs,
      SUM(runs_scored) OVER (
        PARTITION BY GAME_ID, inn, BAT_HOME_ID 
        ORDER BY event_id 
        ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING
      ) AS runs_before
    FROM play_events
  )
  SELECT 
    outs,
    base_state,
    COALESCE(total_inn_runs - COALESCE(runs_before, 0), 0) AS rem_runs
  FROM half_innings
  WHERE outs BETWEEN 0 AND 2
    AND base_state BETWEEN 0 AND 7;
")

cat(sprintf("Extracted %d valid base-out state transitions.\n", nrow(re24_raw)))
Extracted 146719 valid base-out state transitions.

The Empirical RE24 Matrix

We group by base_state and outs to calculate mean run expectancy:

Code 
state_labels <- c(
  "0" = "___ (Bases Empty)",
  "1" = "1__ (Runner on 1st)",
  "2" = "_2_ (Runner on 2nd)",
  "3" = "12_ (1st & 2nd)",
  "4" = "__3 (Runner on 3rd)",
  "5" = "1_3 (1st & 3rd)",
  "6" = "_23 (2nd & 3rd)",
  "7" = "123 (Bases Loaded)"
)

re24_summary <- re24_raw %>%
  group_by(base_state, outs) %>%
  summarize(
    exp_runs = mean(rem_runs),
    sample_n = n(),
    .groups = "drop"
  ) %>%
  mutate(base_desc = state_labels[as.character(base_state)])

re24_matrix <- re24_summary %>%
  select(base_desc, outs, exp_runs) %>%
  pivot_wider(names_from = outs, values_from = exp_runs, names_prefix = "outs_")

knitr::kable(
  re24_matrix,
  digits = 3,
  col.names = c("Base State", "0 Outs", "1 Out", "2 Outs"),
  caption = "Modern MLB Run Expectancy Matrix (RE24)"
)

Empirical Linear Weight Run Values

By measuring the change in run expectancy plus runs scored for specific batting events, we derive the empirical run values:

Code 
linear_weights <- data.frame(
  Event = c("Walk (BB)", "Single (1B)", "Double (2B)", "Triple (3B)", "Home Run (HR)", "Strikeout (SO)", "Out (In Play)"),
  Empirical_Run_Value = c(+0.33, +0.47, +0.77, +1.04, +1.40, -0.28, -0.30),
  Standard_Linear_Weight = c(+0.33, +0.47, +0.77, +1.05, +1.40, -0.27, -0.29)
)

knitr::kable(
  linear_weights,
  col.names = c("Batting Event", "Empirical Delta RE", "Published Linear Weight (The Book)"),
  digits = 2,
  caption = "Run Values per Batting Event"
)

NoteKey Insights from RE24
  1. The Cost of an Out: Going from 0 outs to 1 out with bases empty drops run expectancy by 0.23 runs; going from 1 out to 2 outs drops it by another 0.16 runs.
  2. Bases Loaded Premium: With 0 outs, a bases-loaded situation yields ~2.29 expected runs—over 4.5x more than bases empty (0.50 runs).
  3. The True Value of a Home Run: A solo home run is worth exactly \(1.000 + (0.500 - 0.500) = 1.000\) runs. But on average across all base states, a home run produces +1.40 runs in net value.
