AI Agent Data Manifest & Query Cookbook

Machine-readable schemas, zero-copy DuckDB recipes, and semantic invariants for autonomous AI agents

Overview

Modern AI agents and Large Language Models (LLMs) excel at generating complex analytical queries and statistical models, but frequently fail due to schema hallucinations, incorrect column names, or unawareness of historical edge cases (e.g., COVID-19 shortened season, bat tracking metric availability, or coordinate conventions).

mlbr solves this by maintaining a live machine-readable Data Lake Manifest (lake_manifest.json and agent_context.json) and automated semantic verification routines. This page serves as both human documentation and a direct context payload for AI agents.

Universal ID Join Recipes for AI Agents

AI agents should utilize these verified SQL templates to combine high-speed Statcast telemetry with historical player profiles and team schedules:

1. Statcast Telemetry \(\leftrightarrow\) Universal Player Names & IDs

SELECT 
  sc.game_date,
  sc.pitch_type,
  sc.release_speed,
  sc.plate_x,
  sc.plate_z,
  cw.name_first || ' ' || cw.name_last AS pitcher_name,
  cw.key_retro,
  cw.key_bbref,
  cw.key_fangraphs
FROM v_statcast sc
LEFT JOIN v_chadwick_register cw 
  ON sc.pitcher = cw.key_mlbam
WHERE sc.game_date >= '2024-01-01'
LIMIT 10;

2. Fast Whiff Rate by Pitch Type

SELECT 
  pitch_type,
  count(*) as total_pitches,
  round(avg(release_speed), 1) as avg_mph,
  round(avg(case when description in ('swinging_strike', 'swinging_strike_blocked', 'missed_bunt') then 1.0 else 0.0 end) * 100, 2) as whiff_pct
FROM v_statcast
WHERE pitch_type IS NOT NULL AND release_speed IS NOT NULL
GROUP BY pitch_type
HAVING count(*) > 50000
ORDER BY total_pitches DESC;

3. Bidirectional Game Crosswalk (Retrosheet \(\leftrightarrow\) Statcast)

library(mlbr)
# Retrosheet GAME_ID -> Statcast game_pk
crosswalk_game("BOS202304150", to = "game_pk")
# Returns: 718576

# Statcast game_pk -> Retrosheet GAME_ID
crosswalk_game(718576, to = "GAME_ID")
# Returns: "BOS202304150"

## Live Data Lake Health & Inventory

The table below reflects the live census and semantic health of the canonical data lake:

```{r}
#| label: live-manifest-summary
#| echo: false
#| message: false
#| warning: false
suppressPackageStartupMessages({
  .libPaths(c("/mnt/storage/R/library", .libPaths()))
  library(jsonlite)
  library(dplyr)
  library(knitr)
})

manifest_file <- "/mnt/storage/Rprojects/mlbr/data/manifest/agent_context.json"
if (file.exists(manifest_file)) {
  ctx <- jsonlite::read_json(manifest_file)
  
  sources_df <- do.call(rbind, lapply(names(ctx$sources), function(nm) {
    s <- ctx$sources[[nm]]
    data.frame(
      Source = nm,
      Records = format(s$rows, big.mark = ","),
      Size_MB = sprintf("%.1f MB", s$size_mb),
      stringsAsFactors = FALSE
    )
  }))
  
  cat(sprintf("**Status:** %s | **Last Updated:** %s\n\n", ctx$audit_summary$status, ctx$updated_at))
  knitr::kable(sources_df, col.names = c("Data Source", "Total Records", "Compressed Footprint"))
} else {
  cat("Manifest not found. Run `Rscript R/generate_agent_manifest.R` to compile.")
}
```
