Machine learning, statistical modeling, and empirical sabermetrics gallery

Inspired by scikit-learn’s example gallery, this collection showcases reproducible, publication-ready machine learning workflows, non-linear regression models, and sabermetric analyses built on top of the mlbr data lake.

<p>K-Means and Gaussian Mixture Models (GMM) applied to 3D trajectory and break vectors (<code>pfx_x</code>, <code>pfx_z</code>, velocity, spin). Repertoire discovery without human pitch-tag bias.</p>

Empirical Sabermetrics & Non-Linear Surfaces

<span class="gallery-badge sabermetrics">Q-CRISP Study 02</span>
<span class="gallery-badge">Platoon Physics</span>
<h4><a href="analyses/02_platoon_physics.html">4-Quadrant Platoon Physics &amp; PVI</a></h4>
<p>Full-population RvR, RvL, LvL, and LvR analysis across 14.64M pitches: batter-perspective horizontal break (<code>hb_away_in</code>), CSW%, xwOBA, TTO decay, and Pitcher Platoon Vulnerability Index.</p>
<hr style="margin: 0.75rem 0; border-color: #f1f5f9;">
<small class="text-muted">Out-of-Time CSW% r = 0.886 | xwOBA r = 0.934 | Interactive Plotly</small>
<span class="gallery-badge sabermetrics">Sabermetrics</span>
<span class="gallery-badge">GAM / LOESS</span>
<h4><a href="analyses/xwoba_surface.html">Non-Linear xwOBA & Barrel Landscape</a></h4>
<p>Fitting a 2D Generalized Additive Model (GAM) thin-plate spline over Exit Velocity and Launch Angle to map the continuous probability landscape of hits, extra bases, and Statcast "Barrels".</p>
<hr style="margin: 0.75rem 0; border-color: #f1f5f9;">
<small class="text-muted">Model: 2D Thin-Plate Spline (mgcv) | Batted Balls: Statcast</small>
<span class="gallery-badge sabermetrics">Sabermetrics</span>
<span class="gallery-badge">Retrosheet</span>
<h4><a href="analyses/run_expectancy.html">Run Expectancy RE24 Matrix</a></h4>
<p>Empirical calculation of the 24 base-out run expectancy matrix directly from 23.8 million Retrosheet play events. Inning state transitions, run values per event, and game leverage indexing.</p>
<hr style="margin: 0.75rem 0; border-color: #f1f5f9;">
<small class="text-muted">Dataset: 23.8M Retrosheet Plays | Coverage: 1871–2025</small>
